STAGECRAFT — เว็บไซต์ตัวอย่างบริษัทเวที แสง สี เสียง และจอ LED (ออกแบบใหม่ทั้งหมดแทน 789 Organize)
โดย SOFT Z DIGITAL

หน้าเว็บ
- index.html     ทัวร์ภาพงานจริง 7 ฉาก เลื่อนเมาส์ / กดลูกศร / ปัดจอ แล้วกล้องพุ่งเข้าไปในภาพสู่ฉากถัดไป
- works.html     ผลงาน กรองตามประเภท + กดดูภาพใหญ่
- services.html  บริการ 6 อย่าง + ขั้นตอนการทำงาน
- contact.html   ฟอร์มขอใบเสนอราคา (ตัวอย่าง ยังไม่ส่งข้อมูลจริง)
- credits.html   เครดิตภาพ

ไฟล์สำคัญ
- js/cinema.js   ทัวร์ภาพจริงแบบภาพยนตร์ (Three.js r170 อยู่ใน js/vendor) — ซูมพุ่งเข้าภาพ เบลอตามทิศ แสงรั่ว เกรนฟิล์ม
- js/data.js     ข้อความ ตำแหน่งกล้องแต่ละฉาก ผลงาน บริการ เครดิต
- js/app.js      header/footer, ตัวควบคุมฉาก, หน้าย่อย
- css/style.css  สไตล์ทั้งหมด (ดำ + อำพัน, ฟอนต์ Unbounded + Prompt)
- tools/build-pages.mjs  สร้างหน้าย่อยใหม่: node tools/build-pages.mjs

ภาพ
- ภาพถ่ายทั้งหมดจาก Unsplash (Unsplash License) ปรับโทนให้เข้าธีม เครดิตอยู่ใน credits.html และ js/data.js
- ไม่ได้ใช้ภาพหรือข้อความจากเว็บ/เพจเดิมของ 789 Organize
- เอฟเฟกต์การเคลื่อนกล้องเขียนเองด้วย WebGL shader

ต้องเปิดผ่านเซิร์ฟเวอร์ (เช่น npx serve) เพราะใช้ ES modules — ดับเบิลคลิกไฟล์ HTML ตรง ๆ จะไม่ทำงาน
